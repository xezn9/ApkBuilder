# ApkBuilder

تطبيق أندرويد (Kotlin + Jetpack Compose) يبني مشاريع أندرويد **على GitHub Actions** ثم ينزّل الـ APK ويحفظه على الجهاز.

## كيف يعمل
1. **حساب GitHub**: الصق Personal Access Token (صلاحيتا `repo` و `workflow`) واختر **المستودع**.
2. (اختياري) اختر ملف المشروع `zip`. إن لم تختر شيئاً يفحص التطبيق المشروع الموجود في المستودع.
3. التطبيق **يتعرف على نوع المشروع تلقائياً** ويولّد ملف `.github/workflows/apkbuilder.yml` بنفسه — لا حاجة لاختيار أو كتابة build.yml.
4. اضغط **ابدأ البناء**: يرفع المشروع (مفكوكاً في مجلد `project/`) مع ملف البناء في commit واحد، يشغّل الـ workflow، يتابع الخطوات،
   وعند النجاح ينزّل الـ APK ويحفظه. عند الفشل يحلل السجل ويعرض الأخطاء (ملف/سطر/عمود) في تبويب **السجل**.

## الأنواع المدعومة
- Android (Gradle: Kotlin / Java) — يعمل حتى لو لم يحتوِ المشروع على `gradlew`، ويختار JDK وإصدار Gradle حسب المشروع
- Flutter (ويُنشئ مجلد android إن كان ناقصاً)
- React Native و Expo (يولّد مجلد android بـ prebuild إن لم يوجد)
- Capacitor / Ionic و Cordova
- Python (Kivy / Buildozer)
- مواقع الويب: مجلد HTML بسيط، أو مشروع npm له سكربت build (React / Vue / Vite …) — يُغلَّف كتطبيق عبر Capacitor
- غير مدعوم حالياً: Unity و Godot و .NET MAUI (يظهر سبب واضح عند اختيارها)

> الـ APK الناتج بنسخة debug (أو release موقّعة بمفتاح debug) أي قابل للتثبيت مباشرة، وليس للنشر في المتجر.
